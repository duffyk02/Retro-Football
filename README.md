# Retro Football Pro - Android APK

## Get your APK (no Android Studio needed)

1. Create a free account at github.com
2. Create a new repository (any name)
3. Upload all files from this folder to the repo
4. Go to the "Actions" tab → click the completed "Build APK" run
5. Download the "apk" artifact → install on your Android phone

That's it. Every push rebuilds the APK automatically.
